# Cool_Hotkeys

CTRL + Y -          Toggle Side Menu
CTRL + < -          Toggle Terminal
CTRL + Shift + Y -  Toggle Action Bar
CTRL + Shift + < -  Toggle Status Bar

Shift + Alt + F -   Format Document

Ctrl + Alt + Enter  Run Python File
Ctrl + Alt + Num0   Notebook: Run all Cells
Ctrl + Alt + Num1   Notebook: Run this Cell
